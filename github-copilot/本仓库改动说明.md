# GitHub Copilot 部分 · 本仓库改动说明

本目录是 [Moyxi-Team/copilot-desktop-zh-ai](https://github.com/Moyxi-Team/copilot-desktop-zh-ai)（MIT，Copyright (c) 2026 zhao818）的部署形态快照，用于给 **GitHub Copilot 桌面版 1.4.2** 装中文界面。上游 `LICENSE` 原样保留，`README.md` 为上游原文。

## 部署形态

把本目录**整个复制**到主程序同级，目录名建议 `GitHub Copilot 中文运行版`：

```
%LOCALAPPDATA%\Programs\GitHub Copilot\
├── github.exe                       ← 官方主程序，未改动
└── GitHub Copilot 中文运行版\
    ├── inject.js
    ├── dictionary.json
    ├── 启动 GitHub Copilot 中文版.cmd
    ├── 启动 GitHub Copilot 中文版.vbs
    └── cache\injector.log           ← 运行时自动生成
```

启动器靠 `..\github.exe` 相对路径定位主程序，所以**不能挪到别处**。

## 使用

```powershell
# 先完全退出 Copilot（含 copilotapp / copilot-runtime / copilotapphost）
Get-Process copilotapp,copilot-runtime,copilotapphost,github -ErrorAction SilentlyContinue | Stop-Process -Force

# 再启动中文版
& ".\启动 GitHub Copilot 中文版.vbs"
```

验证：`node tools\probe-copilot.js`（在仓库根目录执行）或看 `cache\injector.log`，正常会打印 `apply: app:replaced:N`。

## 上游设计要点（未改动）

- 注入通道：WebView2 CDP（`--remote-debugging-port=9222 --lang=zh-CN`），仅本机可访问；
- 注入目标页面：`http://tauri.localhost/` 与 `http://127.0.0.1:<port>/canvases/<uuid>`；
- 保活：3 秒轮询 + `MutationObserver`，翻译过的节点打标记（幂等）；
- 跳过 `pre`/`code`/`script`/`style`/`textarea`/`[contenteditable=true]`，**不碰** AI 回复、代码块、会话标题；
- 词典每 3 秒重读一次 → 改词条**热生效**，不用重启；
- 唯一的可选外呼是 `gh api` 拉取上游词典，本机无 `gh` 时只打一条 `spawn gh ENOENT` 警告，不影响使用。
