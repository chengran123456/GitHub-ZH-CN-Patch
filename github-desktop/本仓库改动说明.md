## 我做的改动（仅词条层，未改任何注入逻辑）

### `src/ui-zh.json`：890 → 899 条

补的都是**实测读到的漏译**（来源见 `docs/04-验证与排障.md`）：

| 英文（整串 key） | 中文 |
| --- | --- |
| `There are no uncommitted changes in this repository. Here are some friendly suggestions for what to do next.` | 此仓库没有未提交的更改。这里有一些接下来可以做的事。 |
| `View the files of your repository in Explorer` | 在资源管理器中查看仓库中的文件 |
| `Select your editor in` | 在以下位置选择编辑器： |
| `Open in your external editor` | 在外部编辑器中打开 |

| `Always available in the toolbar for local repositories or` | 本地仓库始终显示在工具栏中，或 |
| `Always available in the toolbar for local repositories or Ctrl+P` | 在本地仓库的工具栏中始终可用，或按 Ctrl+P |
| `menu or Ctrl+Shift+A` | 菜单或 Ctrl+Shift+A |
| `menu or Ctrl+Shift+F` | 菜单或 Ctrl+Shift+F |

> 有 3 条（含 "Ctrl+P" / "Ctrl+Shift+A" / "Ctrl+Shift+F" 的整句版、"menu or Ctrl+…" 单独版）**最终没生效**，原因是这些句子在 DOM 里被拆成多个文本节点，后半段落在 `<kbd>` 里（渲染层按设计跳过 `kbd`）。保留在词典里无害，不影响其它词条。真正生效的是节点级的那条 `Always available in the toolbar for local repositories or`。

## 上游设计要点（未改动）

- 注入点只有两处：`main.js` 头部 `require("./zh-cn/menu.js")`、`index.html` 的 `</head>` 前 `<script defer src="zh-cn/renderer.js">`；
- 菜单补丁只改 `label`，不动 `id` / `role` / `accelerator` / `click`；
- DOM 翻译只做**整串精确匹配**，不做子串/模糊匹配；句式规则强制 `^...$` 锚定；
- 跳过 `pre`/`code`/`kbd`/`samp`/`textarea`/`input`/`script`/`style`/`svg`/`canvas`、`contenteditable`、class 命中 `diff`/`blob`/`monaco-editor`/`cm-editor`/`code-view`/`highlight` 的子树；
- `input` 的 `value` 永不读写，只翻 `placeholder`；
- 全程无网络请求。
